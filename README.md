# CodeZen - Frontend Client

A modern, responsive web application and PWA designed for instant code optimization, syntax bug diagnosis, and smart snippet generation powered by Google Gemini AI.

---

## Live Demo
- **URL:** [https://dev-engine-frontend.vercel.app](https://dev-engine-frontend.vercel.app)

---

## Features
- **Intelligent Code Optimization:** Refactors logic for speed, memory efficiency, and readability.
- **Automated Bug Resolver:** Detects syntax flaws and logical bugs with clear explanations.
- **PWA Ready:** Installable as a native desktop/mobile web app directly from the browser.
- **Saved Snippets Vault:** Local persistence to save and retrieve generated solutions.

---

## Tech Stack
- **Framework:** React.js
- **Styling:** CSS3 (Dark Theme / Modern Developer UI)
- **Deployment:** Vercel
- **API Integration:** CodeZen Express Backend (Gemini API)
